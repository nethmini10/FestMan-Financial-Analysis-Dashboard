
# FestMan Stores - Financial Analysis Dashboard

## Project Overview
This project presents a comprehensive **Financial Analysis Report** for 'FestMan Stores'. The dashboard is designed to track, evaluate, and visualize key performance indicators (KPIs) to help stakeholders understand the company's financial health, regional performance, and product profitability.

## Key Features & Insights
* **KPI Tracking:** Real-time monitoring of Total Sales ($92.3M), Total Orders, Profit, Profit Margin (14.1%), and Discounts, including comparisons between the Current and Prior Year.
* **Geographical Analysis:** Visual breakdowns of Orders and Profit Margins across key countries including Canada, France, United States, Mexico, and Germany.
* **Product & Segment Performance:** In-depth analysis of Profit Margins categorized by business segments (Channel Partners, Midmarket, Government, etc.) and individual products (Paseo, VTT, Velo, etc.).
* **Time-Series Trends:** Monthly and yearly sales trend analysis to identify peak sales periods throughout 2014.
* **Discount Impact:** Analysis of the percentage of discounts offered across different discount bands (High, Medium, Low).

## Tools Used
* Data Visualization & Analytics: Power BI , Advanced Excel
* Data Processing & Cleaning
